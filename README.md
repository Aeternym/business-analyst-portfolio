## Примечание о статусе работ

Портфолио показывает выполненную **аналитическую проектную работу**: исследование, схемы и требования. Предлагаемые решения не выдаются за реализованные функции действующих компаний. Публичные материалы составлены с учётом приватности; оригиналы источников и рабочие документы можно обсудить отдельно.
